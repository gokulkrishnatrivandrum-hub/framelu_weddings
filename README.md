# Framlu Weddings - Wedding Planner & Photography Customizer

കേരളത്തിലെ വിവാഹ ഫോട്ടോഗ്രാഫിക്കും ഇവന്റുകൾക്കുമായി തയ്യാറാക്കിയ സമ്പൂർണ്ണ വെബ് ആപ്ലിക്കേഷനാണ് **Framlu Weddings**. 

വിശദമായ സാങ്കേതിക വിവരങ്ങൾ, ഫ്രണ്ട് എൻഡ്, ബാക്ക് എൻഡ്, ഡാറ്റാബേസ്, സുരക്ഷ, ഇന്റഗ്രേറ്റ് ചെയ്യുന്ന AI ലൈബ്രറികൾ, സമഗ്രമായ റോഡ്മാപ്പ് എന്നിവയ്ക്കായി ദയവായി താഴെ പറയുന്ന ഫയൽ കാണുക:
👉 **[PROJECT_ARCHITECTURE_AND_ROADMAP.md](./PROJECT_ARCHITECTURE_AND_ROADMAP.md)**

## ⚡ Quick Start

```bash
# ഡിപൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യാൻ
npm install

# ഡെവലപ്‌മെന്റ് സെർവർ പ്രവർത്തിപ്പിക്കാൻ
npm run dev
```

ബ്രൗസറിൽ [http://localhost:3000](http://localhost:3000) തുറക്കുക.
അഡ്മിൻ പാനലിനായി [http://localhost:3000/admin](http://localhost:3000/admin) സന്ദർശിക്കുക.
